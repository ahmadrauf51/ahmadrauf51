### 👨‍💻 About me

I'm a **Senior Full Stack Engineer** from Lahore, Pakistan, writing production code since 2018. I design and build web platforms end to end, from database schema and APIs to polished front-end experiences, for clients across the Middle East, Europe and North America.

- 🏗️ **Architecture first:** modular monoliths, microservices, queues and event-driven systems that scale without drama
- ⚡ **Performance-minded:** caching, query tuning and profiling are part of the job, not an afterthought
- 🤖 **AI-enabled products:** document search and Q&A with RAG pipelines, embeddings and LLM integrations
- 🤝 **Remote-ready:** async communication, clean PRs, and ownership from spec to deployment

> 🔒 Most of my work lives in **private client repositories under NDA**. That's why the contribution graph is busy and the public repos are few. Happy to walk through architecture and code samples on a call.
